# Objetivo

Quiero que desarrolles una página web informativa, sencilla, elegante y profesional para una firma de abogados llamada **Ipial_abogados**.

La página será únicamente informativa. No debe incluir CRM, registro de usuarios, panel administrativo, gestión de clientes, historias clínicas, sistemas complejos ni funcionalidades innecesarias.

La firma cuenta únicamente con **dos abogados**, por lo que el sitio debe transmitir una imagen cercana, profesional y confiable.

## Objetivo

La página debe servir como presentación digital de la firma y permitir que una persona pueda conocer rápidamente:

* Quiénes son.
* Qué servicios jurídicos ofrecen.
* Quiénes son los dos abogados.
* Cómo pueden contactarlos.
* Dónde se encuentran.

La página debe estar diseñada principalmente como una **landing page de una sola página**, con pocos apartados y una navegación sencilla.

## Sección principal — Hero

La primera sección debe presentar inmediatamente la firma.

Debe incluir:

* Nombre: **Ipial_abogados**.
* Una frase profesional que transmita confianza y acompañamiento jurídico.
* Una breve descripción de la firma.
* Un botón principal para contactar.
* Un botón secundario para conocer los servicios.

La primera impresión debe ser elegante, seria y profesional.

No utilizar un diseño excesivamente corporativo ni recargar la pantalla con demasiados elementos.

## Sobre Ipial_abogados

Debe existir una sección breve explicando quiénes son.

Debe transmitir:

* Profesionalismo.
* Confianza.
* Atención personalizada.
* Compromiso con los clientes.
* Experiencia y responsabilidad.

El contenido debe ser conciso y fácil de leer.

No inventar años de experiencia, reconocimientos, casos ganados ni otros datos que no hayan sido proporcionados.

## Áreas jurídicas

Debe existir una sección sencilla mostrando las principales áreas de práctica de la firma.

Cada área debe tener:

* Nombre.
* Pequeña descripción.
* Icono o elemento visual relacionado.

Las áreas pueden incluir, según corresponda:

* Derecho civil.
* Derecho de familia.
* Derecho laboral.
* Derecho comercial.
* Derecho administrativo.
* Derecho penal.
* Derecho empresarial.

No es necesario incluir demasiadas áreas. La sección debe mantenerse limpia y fácil de entender.

La estructura debe permitir modificar las áreas posteriormente.

## Nuestros abogados

Debe existir una sección especial para presentar a los dos abogados de Ipial_abogados.

Debe mostrar dos perfiles claramente diferenciados.

Cada perfil debe permitir incluir:

* Fotografía.
* Nombre completo.
* Cargo.
* Especialidad o áreas jurídicas.
* Breve descripción profesional.
* Información académica relevante, si se proporciona.
* Botón de contacto, si corresponde.

No inventar información profesional.

El diseño debe hacer que los dos abogados sean uno de los elementos principales de confianza de la página.

## ¿Por qué elegirnos?

Debe existir una sección pequeña con algunos elementos que expliquen la propuesta de valor de la firma.

Por ejemplo:

* Atención personalizada.
* Comunicación clara.
* Compromiso con cada caso.
* Orientación jurídica profesional.

Debe evitar afirmaciones exageradas o promesas de resultados.

## Contacto

Debe existir una sección de contacto sencilla.

Debe mostrar:

* Teléfono.
* WhatsApp.
* Correo electrónico.
* Dirección de la oficina.
* Horario de atención.

Debe existir un botón destacado para contactar mediante WhatsApp si se dispone de ese canal.

El objetivo es que un visitante pueda contactar con la firma en pocos segundos.

## Ubicación

Debe existir una pequeña sección indicando dónde se encuentra la oficina.

Debe incluir:

* Dirección.
* Ciudad.
* Mapa o referencia visual de ubicación, si se dispone de la información.

No es necesario crear un sistema complejo de mapas.

## Footer

El pie de página debe ser sencillo.

Debe incluir:

* Logo o nombre de Ipial_abogados.
* Información básica de contacto.
* Enlaces a las diferentes secciones.
* Redes sociales profesionales, si existen.
* Aviso de privacidad o información legal básica cuando corresponda.
* Copyright.

## Navegación

La navegación debe ser muy sencilla.

Como máximo debe incluir enlaces a:

* Inicio.
* Nosotros.
* Servicios.
* Abogados.
* Contacto.

Al hacer clic en las opciones, debe llevar al visitante a la sección correspondiente de la landing.

En dispositivos móviles debe existir una navegación adaptada.

## Diseño visual

Quiero un diseño:

* Elegante.
* Profesional.
* Sobrio.
* Moderno.
* Minimalista.
* Fácil de leer.

Debe transmitir confianza y seriedad propias de una firma de abogados.

Evitar:

* Exceso de animaciones.
* Colores demasiado llamativos.
* Demasiados elementos decorativos.
* Diseños sobrecargados.
* Efectos innecesarios.
* Grandes cantidades de texto.

La página debe sentirse como una firma profesional y establecida, pero también cercana.

## Responsive

La página debe funcionar correctamente en:

* Computadores.
* Tablets.
* Teléfonos móviles.

La experiencia móvil debe ser igual de cuidada que la versión de escritorio.

## Velocidad

La página debe ser rápida y ligera.

No debe incluir funcionalidades innecesarias que afecten el rendimiento.

Las imágenes deben estar optimizadas y la página debe cargar rápidamente.

## SEO básico

La página debe estar preparada para aparecer correctamente en buscadores.

Debe incluir:

* Título adecuado.
* Descripción.
* Estructura semántica.
* Encabezados correctamente organizados.
* Información de contacto.
* Datos de ubicación cuando corresponda.

## Contenido

No inventes información sobre los abogados ni sobre la firma.

Cuando falten datos específicos, utiliza contenido temporal claramente identificable para que posteriormente pueda ser reemplazado.

La estructura debe permitir cambiar fácilmente:

* Nombre de los abogados.
* Fotografías.
* Descripciones.
* Servicios.
* Teléfonos.
* WhatsApp.
* Correo.
* Dirección.
* Horarios.
* Redes sociales.

## Resultado esperado

Quiero una landing page sencilla y profesional para **Ipial_abogados**, una firma compuesta por dos abogados.

La página debe centrarse en:

1. Presentar la firma.
2. Mostrar sus principales áreas jurídicas.
3. Presentar a los dos abogados.
4. Transmitir confianza y profesionalismo.
5. Mostrar la ubicación.
6. Facilitar el contacto.

No agregues sistemas de usuarios, CRM, bases de datos complejas, paneles administrativos ni funcionalidades que no sean necesarias para una landing informativa.

La prioridad es conseguir una página **bonita, profesional, rápida, clara y confiable**, donde un visitante pueda entender quién es Ipial_abogados y contactar con ellos en menos de un minuto.

Cuando algún detalle no esté especificado, toma decisiones razonables manteniendo el diseño simple y profesional.

## Stack Tecnológico Definido

**Decisión (2026-08-23): Opción 2 — Astro Híbrido**

**Stack:** `Astro + TypeScript (strict) + Tailwind CSS + React Islands + Astro Content Collections`

**Justificación:**
- 95% estático para SEO y velocidad (Lighthouse 100) — ideal para landing informativa.
- Islas de React solo donde se necesita interactividad puntual (menú móvil, formulario, mapa) sin penalizar el resto.
- Content Collections para editar abogados/servicios/contacto sin tocar código.
- Preparado para fase futura: formularios con persistencia + base de datos (no implementado en fase actual).

**Fase actual:** Landing informativa 100% estática, sin DB ni backend.
**Fase futura prevista:** Formulario de contacto con validación y persistencia (DB/endpoint).

**Integraciones Astro:** `@astrojs/react`, `@astrojs/tailwind`
**Estilos:** Tailwind CSS (diseño sobrio, elegante, minimalista)
**Despliegue:** Build estático (`dist/`) compatible con Dokploy / Nginx.
